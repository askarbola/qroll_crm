Add a Vue component `v-contact-type-toggle` to both create.blade.php and edit.blade.php that handles conditional field visibility. The component uses `data-attribute-code` attributes (added in Plan 01) to find and show/hide fields.

**Field groups:**

Individual fields (show when contact_type = Individual option ID):
- `ssn`
- `date_of_birth`
- `filing_status`
- `occupation`

Business fields (show when contact_type = Business option ID):
- `business_name`
- `ein`
- `entity_type_tax`
- `fiscal_year_end`

**Implementation approach:**

The challenge is that the `<x-admin::attributes>` component renders server-side, and the contact_type dropdown uses option IDs (not text labels) as values. The Vue component must:

1. Use `nextTick` or `MutationObserver` to wait for the form to fully render (the attributes component renders in the same Blade pass, so DOM should be available on mount).

2. Find the `contact_type` select element by targeting `[data-attribute-code="contact_type"] select` or by name `select[name="contact_type"]`.

3. Read the option text to determine which option ID corresponds to "Individual" and which to "Business" (since IDs are auto-generated). Do this by iterating the select options: `option.textContent.trim() === 'Individual'` to get the Individual option value, same for Business.

4. Initially hide all type-specific fields (both individual and business groups).

5. Listen for changes on the contact_type select. On change, show the matching group's fields and hide the other group's fields.

6. Fields are shown/hidden by setting `display: none` / `display: ''` on the closest `[data-attribute-code]` parent div.

**For create.blade.php:**

Add a `@pushOnce('scripts')` block (or extend the existing one) with:

```html
<script type="text/x-template" id="v-contact-type-toggle-template">
    <div><slot></slot></div>
</script>

<script type="module">
    app.component('v-contact-type-toggle', {
        template: '#v-contact-type-toggle-template',

        data() {
            return {
                individualFields: ['ssn', 'date_of_birth', 'filing_status', 'occupation'],
                businessFields: ['business_name', 'ein', 'entity_type_tax', 'fiscal_year_end'],
                individualOptionValue: null,
                businessOptionValue: null,
            };
        },

        mounted() {
            this.$nextTick(() => {
                this.initContactTypeToggle();
            });
        },

        methods: {
            initContactTypeToggle() {
                const select = document.querySelector('[data-attribute-code="contact_type"] select, select[name="contact_type"]');

                if (!select) return;

                // Determine option values by matching option text
                Array.from(select.options).forEach(option => {
                    const text = option.textContent.trim();
                    if (text === 'Individual') this.individualOptionValue = option.value;
                    if (text === 'Business') this.businessOptionValue = option.value;
                });

                // Hide all type-specific fields initially
                this.hideFields([...this.individualFields, ...this.businessFields]);

                // Show correct fields based on current selection (important for edit page)
                this.toggleFields(select.value);

                // Listen for changes
                select.addEventListener('change', (e) => {
                    this.toggleFields(e.target.value);
                });
            },

            toggleFields(selectedValue) {
                if (selectedValue === this.individualOptionValue) {
                    this.showFields(this.individualFields);
                    this.hideFields(this.businessFields);
                } else if (selectedValue === this.businessOptionValue) {
                    this.showFields(this.businessFields);
                    this.hideFields(this.individualFields);
                } else {
                    // No selection -- hide all type-specific fields
                    this.hideFields([...this.individualFields, ...this.businessFields]);
                }
            },

            showFields(codes) {
                codes.forEach(code => {
                    const el = document.querySelector(`[data-attribute-code="${code}"]`);
                    if (el) el.style.display = '';
                });
            },

            hideFields(codes) {
                codes.forEach(code => {
                    const el = document.querySelector(`[data-attribute-code="${code}"]`);
                    if (el) el.style.display = 'none';
                });
            },
        },
    });
</script>
```

The view page (`view/attributes.blade.php`) uses `<x-admin::attributes.view>` which renders attribute labels and values in a read-only format. The view.blade.php component (from Plan 01 Task 2) now has `data-attribute-code` on each attribute row wrapper.

Add inline JavaScript at the bottom of `view/attributes.blade.php` (after the existing content) that:

1. Finds the contact_type value by looking at the text content of the `[data-attribute-code="contact_type"]` element's value cell.
2. If the displayed value is "Individual", hides business field rows.
3. If the displayed value is "Business", hides individual field rows.
4. If no contact type value exists (empty), hides all type-specific rows.

The view page is simpler than the form because there is no interactive selection -- the value is already set and displayed as text.

Implementation:

Add a `@pushOnce('scripts')` block at the end of `view/attributes.blade.php`:

```blade
@pushOnce('scripts')
    <script type="module">
        document.addEventListener('DOMContentLoaded', function() {
            const individualFields = ['ssn', 'date_of_birth', 'filing_status', 'occupation'];
            const businessFields = ['business_name', 'ein', 'entity_type_tax', 'fiscal_year_end'];

            // Find the contact_type display value
            const contactTypeRow = document.querySelector('[data-attribute-code="contact_type"]');

            if (!contactTypeRow) return;

            // The view component renders as: <div class="grid grid-cols-[1fr_2fr]"><div>label</div><div>value</div></div>
            // The value is in the second child div
            const valueCell = contactTypeRow.querySelector('.font-medium');
            const contactTypeText = valueCell ? valueCell.textContent.trim() : '';

            function hideFields(codes) {
                codes.forEach(function(code) {
                    const el = document.querySelector('[data-attribute-code="' + code + '"]');
                    if (el) el.style.display = 'none';
                });
            }

            if (contactTypeText === 'Individual' || contactTypeText.includes('Individual')) {
                hideFields(businessFields);
            } else if (contactTypeText === 'Business' || contactTypeText.includes('Business')) {
                hideFields(individualFields);
            } else {
                // No contact type -- hide all type-specific
                hideFields([...individualFields, ...businessFields]);
            }
        });
    </script>
@endPushOnce
```

Note: The `<x-admin::attributes.view>` component renders select attribute values as the option NAME (text), not the option ID. So we match against the text "Individual" / "Business".

IMPORTANT: The view page uses an inline-editable form (`<x-admin::attributes.view ... :allow-edit="true" />`). When the user edits the contact_type value inline, the page will refresh/reload, so the DOMContentLoaded approach is sufficient. No need for reactive change handling on the view page.

Do NOT modify any existing content in the file. Only ADD the @pushOnce block at the end, before the closing render event line.
