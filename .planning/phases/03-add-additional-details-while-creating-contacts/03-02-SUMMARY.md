**Vue-based conditional visibility toggles Individual/Business fields on person create, edit, and view pages based on Contact Type selection**

## Accomplishments
- Added v-contact-type-toggle Vue component to create and edit person pages that shows/hides fields based on Contact Type dropdown
- Individual fields (SSN, Date of Birth, Filing Status, Occupation) display only when Contact Type = Individual
- Business fields (Business Name, EIN, Entity Type, Fiscal Year End) display only when Contact Type = Business
- All type-specific fields are hidden when no Contact Type is selected
- View page uses DOMContentLoaded script to hide irrelevant type-specific fields based on saved Contact Type text value
- Edit page correctly reads pre-populated Contact Type value on mount and shows the right field group

## Decisions Made
- **Vue component wrapper pattern:** Used a Vue component (`v-contact-type-toggle`) with a `<div><slot></slot></div>` template to wrap the attributes block transparently without breaking form layout
- **Option text matching:** Since Contact Type option IDs are auto-generated by the EAV system, the component iterates select options and matches `textContent.trim()` to determine which value corresponds to "Individual" vs "Business"
- **DOMContentLoaded for view page:** The view page displays a static value (not interactive select), so a simple DOMContentLoaded handler reads the displayed text and hides irrelevant fields -- no reactive framework needed
